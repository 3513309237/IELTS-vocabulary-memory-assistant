# 雅思词汇记忆工具 MVP

双击 `index.html` 即可打开。已录入 Word List 01 的 72 个正文主词条；词库数据在 `words.json`，`words.js` 是为了支持直接打开本地网页而生成的同一份数据。

当前词库版本为 v4：每条独立释义都带有稳定 ID、词性（如 `v.`、`n.`、`adj.`、`adv.`）和一条例句。记忆页、英译中选项和中译英提示均显示词性；英译中按当天任务的最大释义数量生成 3 倍选项（最多 9 个），每个词仍需英译中 2 次和中译英 2 次通过。

每批任务完成后可以点击“今天再设一个任务”追加学习，追加批次继续从 PDF 顺序中下一个尚未过关的词开始。当天累计完成数会单独显示；跨天后只保留永久过关词，未完成批次清除。

进度保存在当前浏览器的 localStorage 中，可在页面底部导出/导入 JSON 备份。v1、v2、v3 进度与 v4 词库不兼容，导入旧版文件会提示重新开始。

页面底部的“清除所有进度”会删除已过关记录、当天任务和检查进度，确认后从当天的任务设置重新开始；词库内容不会被删除。
